# 견적서 로고·제출 문구 및 알림 카드 개선

- 회사 Excel 양식 상단의 PNG 로고를 서명과 구분하여 가져옵니다.
- 견적서 좌측 상단에 원본 비율을 유지한 로고를 표시하고 제목은 가운데 유지합니다.
- `상기 견적서를 제출합니다.` 문구를 중앙 정렬합니다. 대표자·서명은 우측 정렬을 유지합니다.
- 서버의 비공개 `quotation_logo` 설정과 공급자 회사명이 일치하는 새 견적에 로고를 적용합니다. 적용한 이미지의 SHA-256도 견적 스냅샷에 보관합니다.
- 기존 PDF는 변경하지 않습니다. 변경된 디자인은 새 견적 또는 기존 견적의 새 버전 저장 시 반영됩니다.
- 알림 목록을 개별 카드로 구분합니다. 카드 사이 12px, 내부 여백과 둥근 테두리를 적용하고 읽지 않은 알림은 배경·테두리 및 `읽지 않음` 표시로 구분합니다.
- 알림 읽음 처리·필터·화면 이동은 기존 동작을 유지합니다.

## 서버 적용

DB 테이블 마이그레이션은 없습니다. 새 서버 코드 적용 후 회사 양식을 다시 가져오면 로고 설정이 추가됩니다. 기존 공급자·계좌 기본값을 직접 수정했다면 원본 양식과 먼저 비교하세요. `--apply`는 양식의 공급자·계좌·서명·로고 기본값을 저장합니다.

```bash
cd backend
env -u DEBUG -u DATABASE_URL -u ENVIRONMENT \
  .venv-linux/bin/python scripts/import_quotation_defaults.py '/실제/견적서.xlsx'
# 검증 결과와 대상 양식 확인 후 위 명령 끝에 --apply를 붙여 저장합니다.
```

원본 회사 이미지와 개인정보는 공개 예제·테스트 데이터에 포함하지 않습니다. 실제 로고로 만든 로컬 검토 PDF는 사용자별 검증 폴더에 저장합니다.

## 검증

- 모바일 390px / 데스크톱 1440px, 글자 배율 100% / 200%, 라이트 / 다크 8조합: 카드 간격·읽음 처리·레이아웃 오류 검사.
- 견적 API: 로고와 서명 동시 삽입, 회사 불일치 시 미삽입, 기존 PDF 불변성, 대표자 변경 시 로고 유지·서명 미삽입, 다중 페이지와 동시 저장 회귀 검사.
- 양식 로고와 서명 추출 분리 검사, 실제 로고 PDF 미리보기 확인.
