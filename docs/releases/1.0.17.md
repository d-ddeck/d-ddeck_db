# d-ddeck 1.0.17

- 장비 목록에 로봇팔·제어박스 구분 항목을 추가했습니다. PC는 시리얼 번호·제품명·현재 위치, Android는 시리얼 번호·제품명을 표시합니다.
- 현황에 로봇팔·제어박스 대수와 운영 매장 수를 표시하며, 브랜드별 매장 화면에는 운영 매장 수를 표시합니다.
- 구역별 메인 화면 제목과 하위 화면 뒤로가기를 적용했습니다.
- 캘린더 크기를 화면에 맞추고 날짜 더블클릭·더블탭으로 일정을 등록할 수 있습니다. 공유 캘린더 및 Android 위젯 명칭을 정리했습니다.
- 견적서를 흑백 양식으로 변경하고 안내사항 박스, 마지막 페이지 하단 서명, 제출 문구 간격을 조정했습니다.
- 공급자 기본 정보는 작성 화면에서 수정할 수 있습니다. 회사 로고와 서명은 서버 설정에 등록된 이미지를 사용합니다.
- 견적서 작성자 또는 팀장 이상에게 삭제 기능을 제공합니다. 삭제된 버전은 조회와 다운로드에서 제외되고 번호는 재사용하지 않습니다.

## 적용

서버와 앱을 함께 업데이트하세요. DB 마이그레이션 `a840d641cf73`은 견적서 삭제 시각 열을 추가합니다. 기존 견적 PDF는 유지되며 새 양식은 신규 버전 생성 시 적용됩니다.
회사 로고·서명 원본과 운영 DB는 릴리즈에 포함하지 않습니다. 현재 서버에 등록된 공급자·로고·서명 설정을 그대로 사용합니다.
