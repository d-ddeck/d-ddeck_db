# d-ddeck 1.0.6 — 업무 기능 보완 · UI 개선 · 다크모드

대응·장비·매장·근무일지·관리 기능 개선과 24개 UI 개선을 반영한 앱/서버 통합 릴리즈입니다. 앱과 서버를 함께 업데이트하세요.

## 주요 변경

- 시스템/라이트/다크모드와 데스크톱 목록 밀도 설정을 기기에 저장합니다.
- 대응 목록 열 정렬, 필터 개별 해제, 입력 구역 이동, 필수 항목 안내, 상세 상단 작업 버튼을 제공합니다.
- 장비 S/N 고정 열, 매장 상세 탭, 홈 우선 처리 목록, 통계 목적별 구분, 캘린더 날짜 패널을 제공합니다.
- 게시판의 읽음·작성자·첨부 수와 관리자 계정 상세·활성 세션 조회를 추가했습니다.
- 재조회 중 이전 자료와 입력을 보존하고 파일별 업로드 결과, 키보드 단축키, 저장 후 상세 이동을 제공합니다.
- 대응/렌탈·장비 이동/재고·출고 대조·매장 권한·이력 기능을 보완했습니다.
- 여러 기기 로그인과 세션 조회·종료, 인증 보호, 반복 일정·푸시 알림 준비, 백업/복구·배포 설정을 개선했습니다.
- 원격 백업·Firebase·HTTPS/VPN은 설치 환경에 맞는 별도 설정이 필요합니다. 키나 사내 서버 정보는 배포 파일에 포함하지 않습니다.

## 업데이트 전 확인

1. 서버 DB·첨부 저장소·환경 설정을 백업하고 복구 가능 여부를 확인합니다. 이번 버전에는 DB 마이그레이션이 포함되어 있습니다.
2. 서버는 배포 문서의 갱신 절차를 사용합니다. Alembic 미관리 기존 DB는 `adopt_schema.py` 절차를 확인하세요. 운영 DB를 초기화하지 마세요.
3. Windows는 새 설치 파일로 업데이트합니다.
4. **Android는 이번 버전부터 고정 운영 키로 서명합니다. 기존 debug 서명 APK 위에 덮어 설치할 수 없습니다.** 서버 동기화·로컬 임시본·VPN 설정을 확인/백업한 뒤 기존 앱을 제거하고 새 APK를 설치하세요. 이후에는 같은 운영 키로 업데이트합니다.
