# d-ddeck 1.0.4 — 장비·매장 통합, 근무일지, 분류 관리(구 서버 방식), 안드로이드 알람, UI 개편

1.0.3 뒤 쌓인 수정을 한 번에 내놓습니다. 서버 표가 늘었으므로(28 → 30) **서버 설치 파일도 같이 올려야** 합니다.

## 서버

- **근무일지**: 구 서버의 근무일지를 옮겼습니다. 작성자·일자마다 한 장, 직급은 계정의 것, 요약 줄 번호 자동, 연장 근무, 공개 범위(비공개/팀), 임시 저장(계정당 한 장), 첨부, 검색, 엑셀. 구 서버 자료 2건도 함께 왔습니다. 표 `worklogs` · `worklog_drafts` 는 서버를 올리면 자동으로 만들어집니다.
- **서비스구분 · 세부분류를 구 서버 방식 그대로**: 그룹 이름을 서비스구분 / 세부분류로, 구 서버의 서비스구분 12종과 구분별 세부분류 89종을 기본값으로 채택했습니다. 이관 때 이름만 같으면 하나로 합쳐졌던 세부분류('로봇팔 > 엔코더' ≠ '전동 그리퍼 > 엔코더')와 함께 지워졌던 '기타' 구분을 구 서버 자료 기준으로 복구하는 스크립트(`scripts/fix_legacy_symptoms.py`)를 넣었고, 운영 서버에는 이미 반영했습니다(세부 27개 분리 · 원인 줄 278개 재연결 · 불일치 0).
- **분류 항목 관리**: 항목 삭제가 실제로 목록에서 사라집니다(하위 항목도 함께, 기존 기록은 분류 이름 유지). 삭제 전 사용 건수 조회, 재고 상태 규칙에 쓰이는 항목(창고·사무실·미상·설치·렌탈 중·AS 대기·AS 반출)은 삭제 금지, 같은 코드로 다시 추가하면 되살아납니다. 증상 → 서비스구분, 자산 모델·제조사 → 자산 분류의 상하 관계를 서버가 알고, 하위 항목은 상위 없이 만들 수 없습니다.
- **매장 장비 설정**: 재고에 등록되지 않은 S/N 은 거절합니다(아무것도 저장하지 않음). 장비 등록은 [장비 목록]에서만.
- **계정**: 마지막 관리자 계정은 삭제·정지할 수 없습니다.
- **캘린더**: 일정 시각만 바꿔도 사용자가 정한 알림이 유지됩니다.
- 스모크 테스트 207건 · 구 서버 규칙 테스트 145건.

## 앱 (Windows · Android)

- **화면 전면 개편**: 공용 디자인 기반(간격·모서리·색 토큰, 공용 카드·표·필터·확인 창)을 모든 화면에 적용했습니다. 입력 폼에서 도움말과 다음 칸 라벨이 겹치던 문제, 보이지 않던 탭 아이콘을 고쳤습니다.
- **장비·매장 한 영역**: 재고와 매장을 "장비·매장" 탭(현황 · 매장 · 장비 목록 · 위치)으로 합쳤습니다. 매장에 나가 있는 장비를 빼거나 지울 수 있고, 장비 삭제는 팀장 이상(권한이 없으면 항목이 비활성으로 보이며 안내). 매장 장비 설정에서 재고에 없는 S/N 은 입력 무효 처리 후 안내합니다.
- **계정 관리**(관리 › 계정 관리): 계정 목록·검색·상태 필터, 삭제, 권한 변경(일반/팀장/관리자), 정지/해제, 직급 변경.
- **기능 설정의 분류 관리, 구 서버 방식으로**: 세부분류·품명·제조사는 서비스구분(장비 종류)별 표로 나란히 놓이고 표 아래에서 바로 추가합니다. 모든 항목에 ▲▼ 순서(바로 저장), ⋮ 메뉴에 이름 바꾸기 · 상위 변경 · 사용 안 함/다시 사용 · 삭제(사용 건수 확인 창). 화면 용어 '증상' → '세부분류'.
- **접수**: 새 접수는 데스크톱에서 서비스구분 3칸으로 시작(구 서버와 같음), 비어 있는 칸은 저장하지 않습니다.
- **캘린더**: 일정 수정·삭제, 월간 달력에 일정 제목 막대(여러 날 일정은 기간만큼 이어짐), 일정 색 선택, 공휴일 표시.
- **안드로이드 알람**: 일정 알림이 시계 앱 알람처럼 전체 화면·반복 소리·스누즈로 울리고, 앱이 꺼져 있어도 울립니다. 서버와 끊겨도 폰에 동기화된 알람 목록을 볼 수 있고, 로그아웃해도 폰의 알람은 유지됩니다.
- **근무일지** 화면: 목록(내 것/팀/전체) · 작성(임시 저장, 자동 저장) · 상세 · 엑셀.
- 회사 로고를 실행 아이콘으로(Android · Windows · Linux).

## 설치 · 확인할 것

- **서버**: 새 설치 파일(`ddeck-server-1.0.4.run`)로 올리면 표 2개가 자동 생성됩니다. 다른 서버에서 구 서버 자료를 새로 이관한 경우에만 `scripts/fix_legacy_symptoms.py --source <cs.db 폴더> --apply` 를 한 번 돌립니다(이미 운영 중인 서버는 반영 완료).
- **안드로이드**: APK 는 아직 디버그 서명이라 설치 때 "권장하지 않음" 경고가 계속 나옵니다(정식 서명 키는 다음 단계). 알람이 화면을 켜고 울리려면 앱 설정에서 전체 화면 알림 허용과 배터리 최적화 제외가 필요하며, 앱이 안내합니다.
- **Windows**: 1.0.3 설치 위에 덮어 설치하면 됩니다.
