# d-ddeck 1.0.19

- Google 백업 화면에서 rclone 기반 Google 계정 연결·변경과 공유 드라이브 폴더 선택을 지원합니다.
- 백업 파일 목록 조회·다운로드와 서버 복구 기능을 추가했습니다. 서버 PC의 관리자만 복구할 수 있습니다.
- 일반 백업과 복구·업데이트 전 안전 백업을 Google 드라이브에만 보관합니다. 업로드 임시 파일은 작업 후 삭제하며 기존 로컬 백업은 그대로 보존합니다.
- 안전 백업 업로드·검증에 실패하면 복구·업데이트를 중단합니다. rclone 데이터 백업은 최신 30개를 유지하며 업데이트 복구 자료는 별도로 30개를 유지합니다.
- Windows 앱에 WireGuard 설정 파일 등록·연결·해제 기능을 추가했습니다. 공식 WireGuard 설치와 연결 시 관리자 승인이 필요합니다.
- 사전 등록된 서버 PC에서는 최초 실행부터 로컬 관리자 자동 로그인을 지원합니다.

## 적용 안내

서버와 앱을 함께 업데이트하세요. Google 백업 페이지에서 계정과 대상 폴더를 연결하고 자동 백업을 활성화해야 예약 백업이 실행됩니다. 기존 서버의 Google 연결을 먼저 확인하세요. 업데이트 안전 백업에 필요한 연결이 없으면 업데이트를 중단합니다.

실제 DB, 첨부파일, 환경설정과 인증정보는 릴리즈에 포함하지 않습니다. Windows 설치 파일, Android APK, Ubuntu 서버 설치 파일과 서명된 자동 업데이트 정보를 함께 제공합니다.

[Google 백업 및 복구 안내](https://github.com/kmeans12345-cell/d-ddeck_db/blob/v1.0.19/docs/google-drive-backup.md)

자동 검사는 임시 파일 정리, 백업 실패 시 복구 차단, 복구·업데이트 되돌림, 계정 연결 흐름과 클라이언트 UI를 포함합니다. 실제 Google 업로드·복구와 Windows WireGuard 연결은 운영 환경에서 별도 확인이 필요합니다.
