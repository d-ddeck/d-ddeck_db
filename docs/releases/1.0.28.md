# d-ddeck 1.0.28 — 근무일지 PDF·연장근무 자동 계산·열람 범위 고정·게시판 첨부 개선

작성일: 2026-10-07

## 근무일지

- 근무일지 상세 화면의 **PDF** 버튼으로 일지를 PDF로 열거나 저장할 수 있습니다. 오른쪽 위에 견적서와 같은 회사 로고(흑백)가 들어갑니다. 로고는 견적서 설정에 등록한 것을 씁니다.
- **연장 근무 자동 처리**: 연장 근무 O/X 선택을 없앴습니다. 정규 근무 09:00~18:00 기준으로 **18:00 이후 근무만** 연장으로 계산합니다(09:00 이전 근무는 포함하지 않음).
  - 예: 08:00~20:30 → 연장 2시간 30분. 종료가 시작보다 이르면 자정을 넘긴 근무로 봅니다.
  - 18:00 이후 근무가 있으면 **연장 근무 사유** 입력란이 자동으로 나타나며 필수입니다.
  - 목록·상세·PDF·엑셀에 연장 시간을 표시합니다. 이전 일지도 근무시간 기준으로 다시 계산해 보여 줍니다.
- **연장근무 종합**: "내 일지"에서 월 단위로 연장 근무가 있는 날짜, 연장 시간, 사유를 차트와 표로 보고 총 연장근무 시간을 확인합니다. 종합 내용은 PDF로 출력할 수 있습니다.
- **열람 범위 고정**: 공개 범위 선택을 없앴습니다. 근무일지는 **작성자, 같은 부서 팀장, 관리자·최고 관리자**만 볼 수 있습니다. 본문·목록·PDF·첨부·엑셀에 모두 적용됩니다.
  - 팀장은 역할이 팀장(MANAGER)이고 관리 › 사용자에서 부서가 지정되어 있어야 부서원 일지를 봅니다.
  - 목록 상단은 관리자 "내 일지 / 전체 보기", 팀장 "내 일지 / 부서 일지", 일반 사원 "내 일지"만 표시합니다.
  - 이전에 "팀 공개"로 저장한 일지도 새 규칙으로만 열람됩니다.
- 근무일지 쓰기 버튼을 게시판처럼 오른쪽 아래 떠 있는 버튼으로 바꾸고 상단 바를 없애 목록 공간을 넓혔습니다.

## 게시판

- 글쓰기 화면에서 바로 **이미지·파일을 첨부**합니다. 고른 이미지는 썸네일로 보이고, 등록할 때 함께 올라갑니다. "저장 후 첨부" 버튼은 없앴습니다.
- 글 수정 화면에서는 기존 첨부를 그 자리에서 추가·삭제할 수 있습니다.

## 알림·대시보드

- 알림 화면의 **초기화**를 누르면 확인 후 내 알림을 모두 지웁니다(다른 사람 알림은 그대로).
- **종결률**은 전체 기간 기준 `(전체 건수 − 미종결 건수) ÷ 전체 건수`로 계산합니다. 취소 건은 미종결이 아니므로 종결 쪽에 포함됩니다. AS 통계 화면의 종결률도 같은 식을 씁니다.

## 배포 및 확인

- 앱 버전 1.0.28+28. 앱·업데이트 서명 키는 유지합니다.
- **서버도 1.0.28로 갱신해야 합니다.** 근무일지 PDF·연장근무 종합·알림 초기화 API가 추가되고 근무일지 열람 규칙과 종결률 계산이 바뀌었습니다. DB 스키마 변경은 없어 마이그레이션은 필요 없습니다.
- 1.0.27 앱으로 1.0.28 서버에 접속하면 연장 근무를 O/X로 고르는 대신 서버가 근무시간으로 정하며, 연장 사유가 없으면 저장이 거부될 수 있습니다.
- 백엔드 스모크·회귀 테스트, Flutter 정적 분석·전체 테스트를 통과했습니다. 게시판 이미지 첨부와 PDF 저장은 실제 Windows·Android 기기 확인이 필요합니다.
