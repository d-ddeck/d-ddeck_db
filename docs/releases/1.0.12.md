# d-ddeck 1.0.12 — 검색·입력 제목 잘림 수정

Windows 캘린더에서 ‘참석자 검색’ 제목이 잘리던 문제를 수정했습니다. 스크롤 영역 위로 벗어나는 입력 제목을 위해 글자 배율에 맞는 내부 여백을 확보했습니다.

- 캘린더의 참석자 검색: 좌우 분할 화면과 단일 스크롤 화면 모두 수정했습니다.
- 공통 검색 필터: 데스크톱 첫 줄 제목의 여백을 확보했습니다. 계정 검색·근무일지·AS 통계 등에도 적용됩니다.
- AS 상세 검색 조건, 상태 변경, 작업 기록 추가: 내부 스크롤의 첫 입력 제목이 잘리지 않도록 보완했습니다.

## 검증

UI 소스 73개와 입력 제목 선언 93곳을 점검했습니다. 캘린더 24개 조합과 공통 입력 패턴 24개 조합에서 글자 배율 100/150/200%, 라이트·다크모드, 기본·촘촘한 간격을 검증했습니다. 전체 Flutter 테스트 221개 통과, 기존 실서버 의존 19개 생략, 정적 분석 오류 없음.

Windows 테마 설정을 사용한 테스트는 Linux 호스트에서 실행했습니다. Windows 실기기의 실제 글꼴·디스플레이 배율과 OS 설치 과정의 최종 검수는 별도입니다.

[전체 점검 결과](https://github.com/kmeans12345-cell/d-ddeck_db/blob/v1.0.12/docs/FIELD_LABEL_REVIEW.md)

## 업데이트

- **1.0.8 이상:** 앱 재실행 또는 설정 → 업데이트 확인에서 다운로드·설치합니다. 사내 서버에 이번 릴리스가 게시되어 있어야 합니다.
- **1.0.7 이하:** 이번 설치 파일로 한 번 직접 업데이트하세요.
- 기존 1.0.8 이상 서버를 계속 사용할 수 있습니다. 서버 재시작·DB 마이그레이션은 필요 없습니다.
- Android는 기존 운영 서명 키를 유지합니다. OS 설치 화면에서 승인이 필요합니다.

배포 파일은 `SHA256SUMS`, 앱 업데이트 정보는 서명된 `update-manifest.json`으로 검증합니다.
