# d-ddeck 1.0.29 — 근무일지 오전·오후 업무와 문서번호

작성일: 2026-10-07

## 근무일지

- 근무일지 작성의 "금일 업무" 맨 앞에 **오전 업무**·**오후 업무** 입력란을 추가했습니다(선택 입력). 넓은 화면에서는 나란히, 휴대폰에서는 위아래로 놓입니다.
  - PDF에는 오전·오후 업무가 나란히 놓인 표로 출력됩니다. 한 줄이 한 행이며 길면 다음 쪽으로 이어집니다. 둘 다 비어 있으면 표를 출력하지 않습니다.
  - 상세 화면과 엑셀에도 오전·오후 업무가 표시됩니다.
- 근무일지 PDF에서 "열람 범위" 항목을 빼고 **문서번호**를 넣었습니다.
  - 형식 `WL-YYYYMMDD-순번`. 날짜는 일지를 등록한 날(한국 시간), 순번은 그날 등록된 순서입니다.
  - 삭제된 일지도 순번에 포함되어 한 번 매겨진 번호는 바뀌지 않습니다.

## 배포 및 확인

- 앱 버전 1.0.29+29. 앱·업데이트 서명 키는 유지합니다.
- **서버도 1.0.29로 갱신해야 합니다.** DB 마이그레이션 `c062f863e195`가 `worklogs`에 오전·오후 업무 열을 추가합니다. `update.sh`는 마이그레이션을 자동으로 실행합니다. 직접 파일을 교체한 경우 `alembic upgrade head`를 실행합니다.
- 마이그레이션 후에는 DB 구조 버전이 바뀌어, 그 이전에 만든 Google 드라이브 백업은 앱의 "서버 복구"로 바로 복구할 수 없습니다. 서버 갱신 후 Google 백업 화면에서 **지금 백업**을 실행해 새 기준 백업을 만들어 두세요.
- 1.0.28 이하 앱은 오전·오후 업무를 표시하거나 입력하지 않지만 서버 1.0.29와 함께 쓸 수 있습니다.
- 백엔드 스모크·회귀·마이그레이션 테스트, Flutter 정적 분석·전체 테스트를 통과했습니다.
