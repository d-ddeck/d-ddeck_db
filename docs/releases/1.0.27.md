# d-ddeck 1.0.27 — 서버 PC 교체·새 보안 인증서·Google 연결 개선

작성일: 2026-10-07

## 서버 PC 교체 (중요)

- 업무 서버가 새 PC로 바뀌었습니다. 새 서버 주소는 **`https://192.168.121.6`**입니다(이전 `192.168.121.2`).
- 이전 서버의 보안 키를 복구할 수 없어 회사 CA 인증서와 연결 설정 서명키를 새로 발급했습니다. 앱에 새 CA 공개 인증서와 새 서명 공개키가 들어갑니다.
- **기존 앱(1.0.26 이하)은 새 서버에 접속할 수 없고 앱 내 자동 업데이트도 받을 수 없습니다.** 모든 Windows·Android 기기에 1.0.27을 직접 설치해야 합니다.
- 설치 후 관리자가 전달한 새 연결 파일(`ddeck-connection.json`)을 로그인 화면의 **관리자 연결 설정 가져오기**로 적용합니다. 이전에 받은 연결 파일은 사용할 수 없습니다.
- Windows 설치 파일의 기본 서버 주소도 `https://192.168.121.6`으로 바뀌었습니다.

## Google 공유 드라이브 백업 연결

- 서버를 시스템 서비스로 실행할 때 Google 로그인 브라우저가 열리지 않던 문제를 고쳤습니다. 서버 PC 앱이 Google 로그인 링크를 받아 브라우저로 열고, 열리지 않으면 **Google 로그인 열기** 버튼을 표시합니다.
- 백업 다운로드·복구 중 예상하지 못한 오류가 나면 서버 로그에 원인을 기록합니다.

## 서버 운영 참고

- Google 연결의 폴더 적용에는 rclone 1.64 이상이 필요합니다. Ubuntu 기본 패키지(1.60)는 동작하지 않으므로 rclone 공식 패키지를 설치합니다.
- 표준 설치(`/opt/ddeck`)에서 앱 복구 기능을 쓰려면 DB가 SQLite이고, 첨부파일 경로(`STORAGE_DIR`)가 서비스 쓰기 허용 경로 안(`/opt/ddeck/data/storage`)에 있어야 하며, systemd에 `RCLONE_CONFIG=/opt/ddeck/data/rclone/rclone.conf`를 지정해야 합니다.

## 배포 및 확인

- 앱 버전 1.0.27+27. 앱·업데이트 서명 키는 유지합니다.
- 서버 API·DB 스키마 변경은 없습니다. 서버는 Google 연결·복구 처리와 버전 표기가 바뀝니다.
- 새 서버의 HTTPS(사설 CA, `192.168.121.6`)와 실제 사내망·VPN 기기 접속은 서버 적용 후 확인이 필요합니다. 공유기 WireGuard의 허용 대역에 `192.168.121.6`이 포함되어야 합니다.
