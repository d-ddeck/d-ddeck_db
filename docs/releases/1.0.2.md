알아둘 것
--------
  - Windows 설치 파일은 이 우분투 PC 에서 만들 수 없어 따로 빌드한다.
    Windows PC 에서:  .\installer\build.ps1 -ServerUrl "http://192.168.0.20:8000" -Version 1.0.2
  - VPN 켜기/끄기는 안드로이드에서만 된다. Windows·Linux 는 공식 WireGuard 클라이언트를 쓴다.
  - 통계 숫자는 구 서버와 같은 방식이지만, "대표 분류" 기준 숫자와 "원인 수" 기준 숫자가
    다를 수 있다(한 건에 분류가 여러 개). 화면에 둘 다 표시된다.
