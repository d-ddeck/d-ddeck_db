# d-ddeck 1.0.7 — 관리 화면 검색창 잘림 수정

계정 관리·감사 로그에서 검색창에 입력하면 제목이 위쪽으로 잘려 보이던 문제를 수정했습니다.

## 수정 내용

- 관리 탭 내부에 검색창 제목이 표시될 여백을 확보했습니다.
- 좁은 화면의 검색 조건을 펼치거나 가로 스크롤할 때도 제목이 잘리지 않도록 보완했습니다.
- 글자 확대에 맞춰 여백이 조정됩니다.

## 검증

390px·1440px 화면, 기본·200% 글자 크기, 라이트·다크의 8가지 조합에서 계정 관리와 감사 로그를 확인했습니다. 수정 전 잘림을 재현했고 수정 후 모두 통과했습니다. 전체 앱 테스트 127개 통과, 기존 실서버 의존 테스트 19개 생략, 정적 분석 오류 없음.

## 업데이트

- Windows: 새 설치 파일로 덮어 설치합니다.
- Android: **1.0.6과 동일한 운영 키**로 서명하므로 1.0.6 위에 덮어 설치할 수 있습니다. 1.0.5 이하 debug 서명 APK에서 전환한다면 서버 동기화·로컬 임시본·VPN 설정을 확인/백업한 후 최초 한 번 재설치해야 합니다.
- 서버: 이번 버전은 화면 수정이며, 1.0.6 대비 서버 기능·DB 스키마 변경은 없습니다. 1.0.6 서버를 계속 사용할 수 있습니다. 서버 패키지는 버전 일치를 위해 함께 제공합니다.

[사용자 가이드](https://github.com/kmeans12345-cell/d-ddeck_db/blob/v1.0.7/docs/사용자-가이드.md) · [배포 안내](https://github.com/kmeans12345-cell/d-ddeck_db/blob/v1.0.7/deploy/README.md)

다운로드 파일은 함께 제공하는 `SHA256SUMS`로 확인할 수 있습니다. Windows·Android 실기기에서의 최종 사용자 검수는 별도입니다.
