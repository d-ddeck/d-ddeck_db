# d-ddeck 1.0.22 — Windows VPN 설정 보존

작성일: 2026-10-01

## 개선 내용

- Windows에서 VPN 설정 파일을 등록할 때 `AllowedIPs`와 DNS를 기본적으로 자동 변경하지 않습니다. 공식 WireGuard에서 정상 작동하는 접속 경로와 DNS 설정을 유지합니다.
- Android의 기존 분할 터널 기본 동작과 명시적인 분할 터널 변환은 유지합니다.
- Windows VPN 화면에 공식 WireGuard와 앱 VPN 중 한쪽만 연결하도록 안내합니다.
- 이전 버전에서 변환되어 저장된 VPN 설정은 원본을 복원할 수 없으므로 정상 작동하는 `.conf` 파일을 다시 등록하도록 안내합니다.

## 업데이트 후 사용 방법

1. 앱 VPN과 공식 WireGuard의 터널을 모두 해제합니다.
2. 앱 VPN 설정에서 기존 등록을 해제합니다.
3. 공식 WireGuard에서 정상 작동하는 원본 `.conf` 파일을 앱에 다시 등록합니다.
4. 공식 WireGuard 터널을 비활성화한 상태로 앱 VPN만 연결하고 서버 접속을 확인합니다.

공식 WireGuard만 활성화해 앱을 사용하는 방식도 가능합니다. 동일한 설정의 두 터널을 동시에 켜지 마세요. 관리자 서버 연결 설정 JSON은 이 변경 때문에 다시 등록할 필요가 없습니다.

## 검증과 적용 범위

- VPN 설정 보존·명시적 분할 터널·권한 오류·UI 회귀 테스트 34개 통과.
- Flutter 전체 테스트 282개 통과, 환경별 테스트 19개 건너뜀.
- Dart 전체 분석 및 Python Ruff 검사 통과.
- Windows 실제 PC에서 일반 권한 연결과 서버 접속의 최종 검증은 배포 후 필요합니다.
- 클라이언트 동작 개선이며 DB 스키마·서버 API 변경은 없습니다. 운영 서버 1.0.21과 호환됩니다.
- 앱 버전: 1.0.22+22. 기존 Android 서명 키와 업데이트 서명 키를 유지합니다.
