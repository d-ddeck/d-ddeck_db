# d-ddeck 1.0.10 — Android 홈 화면 일정 알람 위젯

휴대폰에 저장된 일정 알람을 Android 홈 화면에서 확인할 수 있습니다.

- 앞으로 울릴 알람을 시간순으로 최대 50개 표시합니다. 제목·알람 시각·캘린더·장소를 확인하고 목록을 스크롤할 수 있습니다.
- 항목을 누르면 앱에서 저장된 상세를 엽니다. 오프라인에서도 확인할 수 있으며, 저장한 계정으로 로그인하면 서버의 최신 일정 상세로 이동할 수 있습니다.
- 새로고침 버튼, 위젯 크기 조절, 시스템 라이트·다크 모드를 지원합니다.
- 앱에서 알람을 동기화하거나 모두 지우면 위젯도 갱신됩니다.

## 사용 방법

앱 업데이트 후 한 번 실행하고, 홈 화면의 빈 곳을 길게 눌러 **위젯 → d-ddeck 일정 알람**을 추가하세요.

위젯은 **이 폰의 알람**에 저장된 예정 알람을 표시합니다. 서버 알림함의 미확인 AS·게시판 알림과는 별도입니다. 새로고침은 저장 목록을 다시 읽으며, 서버 변경 사항은 앱에서 **다시 동기화**해야 합니다. 로그아웃 후에도 기존 알람 정책에 따라 저장 목록이 유지됩니다.

[위젯 사용법과 갱신 기준](https://github.com/kmeans12345-cell/d-ddeck_db/blob/v1.0.10/docs/ANDROID_ALARM_WIDGET.md)

## 검증 및 업데이트

Flutter 테스트 166개 통과, 기존 실서버 의존 테스트 19개 생략, 정적 분석 오류 없음. 로컬 ARM64 릴리스 APK 빌드와 기존 운영 키 서명을 확인했습니다. 홈 화면 런처 및 OS 설치 과정의 실기기 검수는 별도입니다.

- **1.0.8 이상:** 앱 재실행 또는 설정 → 업데이트 확인에서 설치합니다. 사내 서버에 이번 릴리스가 게시되어 있어야 합니다.
- **1.0.7 이하:** 설치 파일로 한 번 직접 업데이트하세요.
- 기존 1.0.8 이상 서버를 계속 사용할 수 있습니다. 서버 재시작·DB 마이그레이션은 필요 없습니다.
- Android는 기존 운영 서명 키를 유지합니다. 설치 화면에서 OS 승인이 필요합니다.

배포 파일은 `SHA256SUMS`, 앱 업데이트 정보는 서명된 `update-manifest.json`으로 검증합니다.
