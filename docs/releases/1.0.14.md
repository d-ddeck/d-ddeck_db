# d-ddeck 1.0.14 — 견적서 로고·알림 카드·서버 운영 안내

## 변경 사항

- 회사 Excel 양식의 상단 로고를 견적서 좌측 상단에 표시합니다. 원본 비율을 유지하고 제목은 중앙에 배치합니다.
- 하단의 “상기 견적서를 제출합니다.” 문구를 중앙 정렬했습니다. 대표자·서명은 우측 정렬을 유지합니다.
- 알림마다 여백과 테두리가 있는 카드 박스를 적용했습니다. 읽음/읽지 않음 상태를 글자로 표시하고, 모바일·데스크톱과 라이트·다크 모드를 지원합니다.
- 현재 SQLite 설치본용 DB 백업 후 재시작 스크립트를 추가했습니다. 실제 복사 진행률, 백업 무결성·DB 구조 검사 후 재시작, 정상 응답 확인을 지원합니다.
- 서버 실행·백업·업데이트·복구·장애 대응을 담은 운영 매뉴얼 PDF를 배포 파일에 추가했습니다.

## 적용 방법

- 1.0.13 서버 기준으로 추가 DB 테이블 마이그레이션은 없습니다. 서버 코드와 앱을 함께 업데이트하세요. 1.0.12 이하 서버에서 업데이트하면 1.0.13의 DB 마이그레이션도 필요합니다.
- **로고는 서버별 설정이 필요합니다.** 기존 회사 양식을 `backend/scripts/import_quotation_defaults.py`로 다시 가져오면 공급자·계좌·서명과 함께 로고를 저장합니다. 먼저 `--apply` 없이 검증하고 대상 양식을 확인한 뒤 `--apply`를 붙여 적용하세요. 직접 수정한 기본값이 있다면 양식의 값과 먼저 비교하세요.
- 로고는 설정된 공급자 회사명과 견적의 회사명이 일치할 때 적용합니다. 기존 PDF는 변경하지 않으며 새 견적 또는 새 버전 저장 시 변경된 디자인이 반영됩니다.
- 현재 바탕화면 설치본의 `ddeck-restart`는 등록된 로컬 단축 명령입니다. 다른 설치에서는 `./deploy/restart-with-backup.sh`로 실행할 수 있습니다. 이 도구는 SQLite·ddeck 서비스·8000 포트용이며, PostgreSQL에서는 사용하지 않습니다. `systemctl restart` 자체에 백업 기능을 추가한 것은 아닙니다.
- DB 백업에는 견적 PDF가 포함되지만 업로드 첨부파일은 포함되지 않습니다. 전체 백업과 복구 방법은 운영 매뉴얼을 확인하세요.

Windows 설치 파일, 기존 키로 서명한 Android APK, Ubuntu 서버 설치 파일, 사용자 가이드 및 서버 운영 매뉴얼을 제공합니다. SHA256SUMS로 파일 무결성을, 서명된 update-manifest.json으로 자동 업데이트 파일을 검증합니다.

## 검증

Flutter 정적 분석 통과, 테스트 245개 통과(실서버 계약 테스트 19개 생략). 서버 기본 검증 254개 및 견적서 PDF·로고/서명 구분·이력 보존 검증 통과. 알림 카드는 화면 폭 390/1440px, 글자 배율 100/200%, 라이트/다크 8조합을 확인했습니다. 재시작 명령은 온라인 SQLite 백업과 실패 시 재시작 차단 테스트를 통과했습니다.
