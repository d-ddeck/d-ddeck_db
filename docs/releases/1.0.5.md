# d-ddeck 1.0.5 — 화면 간격 정리 · 대응 기록 삭제

1.0.4 를 Windows 에서 써 보며 지적된 "요소끼리 너무 붙어 보이는" 곳을 전 화면에서 정리하고, 대응 기록 삭제를 붙였습니다. 서버 변경은 없습니다(1.0.4 서버 그대로 사용).

## 앱 (Windows · Android)

- **간격 규칙**을 정해 전 화면에 적용했습니다: 세로로 쌓이는 카드 사이 12px, 목록 행 사이 8px, 다이얼로그 안 필드 사이 12px, 요약 카드·하단 버튼 줄과는 16px. 대시보드 · 대응 · 장비·매장 · 근무일지 · 캘린더 · 게시판 · 관리 화면 모두.
- **종결 처리 창**: 폭 고정, 대응 내용 · 대응인원 · 대응일 · 변경 메모 · 작업 시간 사이 간격, 가운데 떠 있던 대응일 버튼을 왼쪽 정렬.
- **AS 상세**: 붙어 있던 카드들(기본 정보 · 원인 · 대응인원 · 접수 정보 · 이력 · 첨부)을 띄움.
- **대응 기록 목록**: 행 사이 간격, 오른쪽 끝에서 잘리던 [엑셀] 버튼 여백.
- **자동 통계**: 잘리던 비율% 열은 표를 가로로 넘겨 볼 수 있게.
- **장비 목록**: 표 머리와 겹치던 "n대" 표시를 필터 줄 오른쪽으로, 열 이름 줄 표시.
- **대응 기록 삭제**: AS 상세 ⋮ 메뉴에 [삭제]. 팀장 이상만(아니면 비활성 표시), 확인 창 뒤 목록으로 돌아가며 갱신. 서버는 숨김 처리하고 감사로그에 남깁니다.

## 설치

- Windows: 1.0.4 위에 덮어 설치. 안드로이드: APK 덮어 설치(디버그 서명 경고는 그대로). 서버는 그대로 둡니다.
