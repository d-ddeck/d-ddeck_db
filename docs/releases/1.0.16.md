# d-ddeck 1.0.16 — 발생일 기준 접수번호와 Android 장비 목록

## 변경 사항

- 접수번호 연월을 한국 시간 기준 발생일에서 계산합니다. 신규 등록과 업무 구분 변경 시 모두 적용합니다.
- 발생월을 변경하면 새 번호를 발급하며 같은 발생월 안의 날짜 변경은 번호를 유지합니다. 이전 번호는 재사용하지 않습니다.
- 저장 결과에 접수번호 변경 전후를 안내하고 작업 기록과 감사 이력에 남깁니다.
- 재발급된 기록의 API 응답에서는 legacy_no를 null로 전달하여 이전 Windows·Android 앱도 ticket_no를 표시하게 합니다. 원래 번호는 DB에 보존합니다.
- Android 재고 장비 목록에는 시리얼 번호와 품목명만 표시하고, 항목 선택 시 상세 화면으로 이동합니다.
- 서버 설치 파일과 Git 추적에서 실행 로그·PID·실제 업로드 파일을 제외합니다.

## 적용

서버와 앱을 함께 업데이트하세요. Android 목록 변경은 새 APK 설치 후 적용됩니다.
이번 버전은 추가 DB 마이그레이션이 없으며 최종 리비전은 f739c530be62입니다.
기존 자료의 업무 구분 변경이나 접수번호 일괄 발급은 업데이트 자체로 실행되지 않습니다.

## 검증

백엔드 회귀 스크립트 12개, 배포 단위 테스트 33개, Ruff 정적 검사 및 버전 일치 검사를 통과했습니다. 발생월 채번, 한국 시간 월 경계, 재발급 이력, 중복 방지, 저장 실패 롤백과 이전 앱 표시 호환을 포함합니다.
로컬 환경에 Flutter SDK가 없어 Flutter 분석·테스트 및 Windows·Android 빌드는 아직 수행하지 못했습니다. GitHub 릴리즈 워크플로에서 PostgreSQL·Flutter 검증 후 설치 파일을 빌드합니다.
