# d-ddeck 1.0.25 — 접수 단계화·일정 연동·견적서 체크리스트·백업 후 전원 끄기

작성일: 2026-10-06

## 서비스 접수

- 신규 접수를 단계별로 진행합니다: ① 내용 접수 → ② 견적서 작성(건너뛰기 가능) → ③ 일정 등록(건너뛰기 가능) · 처리 상태.
- 접수 건은 마지막 단계에서 **진행중** 또는 **종결**을 고르고 저장할 때 한 번에 저장됩니다. 작성한 견적서와 일정은 그 직후 같은 건에 등록됩니다.
- 종결을 고르면 서비스 내용·서비스인원·서비스일을 팝업 없이 화면에서 바로 입력합니다.
- 1단계로 돌아가도 입력한 접수 내용은 유지됩니다. 기존 건 수정 화면에는 "저장 후 견적서 작성", "저장 후 일정 등록"이 그대로 있습니다.

## 서비스 건 ↔ 캘린더

- AS 상세에 **연결 일정** 카드를 추가합니다. 이 건에서 등록한 일정을 보고, 매장·현장 주소·접수 내용·담당자가 채워진 일정을 바로 등록할 수 있습니다.

## 견적서 체크리스트

- 관리 > **견적서 체크리스트**에서 관리자가 항목(예: 레인보우 입고)을 만들고, 체크했을 때 안내사항에 추가할 문구와 추가할 품목을 정합니다.
- 견적서 작성 화면에서 항목을 체크하면 안내사항과 품목이 자동으로 채워지고, 체크를 풀면 손대지 않은 내용만 다시 빠집니다. 체크 상태는 다음 견적 버전에 이어집니다.
- 일반 서비스 설정 화면의 JSON 설정(공급자 정보·서명·체크리스트)은 글자 편집으로 깨지지 않도록 읽기 전용으로 표시합니다.

## 백업 후 PC 전원 끄기 (선택)

- Google 공유 드라이브 백업 화면에 **백업 후 PC 전원 끄기**를 추가합니다. 켜면 유예 시간과 다시 켤 시각을 정할 수 있습니다.
- 예약 시각에 실행된 자동 백업이 성공했을 때만 끄고, 유예 중에는 관리자에게 알림이 가며 이번만 취소할 수 있습니다. 수동 백업이나 PC가 켜진 직후 밀린 백업 뒤에는 끄지 않습니다.
- 서버 PC에 전원 제어 도우미를 한 번 설치해야 합니다: `sudo python3 deploy/power_helper.py --install`. 처음 사용할 때 설정한 시각에 실제로 켜지는지(BIOS RTC 켜짐 설정) 확인하세요. 꺼져 있는 동안 앱 접속과 VPN이 끊깁니다.

## 배포 및 확인

- 앱 버전 1.0.25+25. 기존 앱·업데이트 서명 키를 유지합니다.
- **서버도 1.0.25로 갱신해야 합니다.** 새 API(연결 일정, 접수 전 견적서 기본값, 체크리스트, 전원 끄기)와 설정 항목이 추가됐습니다. DB 스키마 변경은 없어 마이그레이션은 필요 없습니다.
- 서버 1.0.24에서는 연결 일정 목록·접수 중 견적서 작성·체크리스트가 동작하지 않고, 종결 서비스일이 저장 시각으로 기록됩니다.
- 백엔드 회귀 테스트(체크리스트·전원 끄기·도우미 포함)와 Flutter 정적 분석·전체 테스트를 검증한 후 배포합니다.
