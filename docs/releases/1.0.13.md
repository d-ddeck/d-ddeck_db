# d-ddeck 1.0.13 — 업무 구분·견적서·매장 연락 정보

## 변경 사항

- 서비스 대응을 AS·CS·PO로 구분하고, 관리 화면에서 업무 구분을 추가할 수 있습니다. 목록·검색·통계·Excel 내보내기에 반영됩니다. 기존 대응 번호는 유지합니다.
- 대응 건별 견적서 작성 및 PDF 열기·저장을 지원합니다. 수정할 때마다 새 버전과 파일명을 만들며, 이전 PDF와 작성 당시 정보를 보존합니다.
- 회사 양식의 공급자 정보와 서명 이미지를 가져올 수 있습니다. 제출·대표자 문구는 우측 정렬하며, 회사명·대표자가 일치하는 새 견적서에 서명을 표시합니다.
- 매장별 담당자·연락처·주소를 저장하고 새 대응일지와 견적서 수신자 정보에 자동 입력합니다. 건별 수정이 가능하며 기존 대응일지와 저장된 PDF는 유지합니다.

## 업데이트 순서 — 서버 업데이트 필요

1. 운영 DB와 서버 설정을 백업합니다. 견적 PDF도 DB에 저장되므로 DB 백업에 포함됩니다.
2. 서버를 1.0.13으로 업데이트하고 새 의존성을 설치한 뒤, 서버 가상환경에서 `alembic upgrade head`를 실행합니다. 기존 배포의 `deploy/update.sh`는 백업·의존성 설치·마이그레이션을 수행합니다. 실제 설치 경로와 서비스 환경에 맞춰 실행하세요.
3. 서버 상태와 버전을 확인한 뒤 Windows·Android 앱을 업데이트합니다. 구버전 서버에는 신규 API가 없어 새 기능을 사용할 수 없습니다.
4. 회사 양식의 공급자·서명은 서버별로 설정합니다. 원본 Excel·서명·계좌 정보는 배포 파일에 포함하지 않습니다. `backend/scripts/import_quotation_defaults.py`는 기본 실행으로 검증하며, `--apply`로 저장합니다.

마이그레이션은 업무 구분, 견적서 이력 테이블, 매장 연락 정보 순서로 적용됩니다. 최종 리비전은 `d527a318fc40`입니다. DB를 되돌리면 견적 이력이 제거될 수 있으므로 백업 없이 다운그레이드하지 마세요.

- 앱 1.0.8 이상은 설정 → 업데이트 확인 또는 재실행으로 업데이트할 수 있습니다. 사내 서버에 릴리즈가 게시되어 있어야 합니다.
- Android는 기존 운영 서명 키를 유지하며 OS 설치 승인이 필요합니다.
- 배포 파일은 `SHA256SUMS`, 자동 업데이트 정보는 서명된 `update-manifest.json`으로 확인합니다.

## 검증

로컬 Flutter 정적 분석 통과, 테스트 237개 통과(실서버 계약 테스트 19개 생략), 서버 기본 검증 254개 통과. 업무 구분, 견적 PDF·이력 불변성·동시 저장, 연락 정보 자동 입력, 마이그레이션 검증 및 Linux 빌드 완료. 릴리즈 CI에서 PostgreSQL·전체 회귀 검사와 Windows·Android·서버 패키지 빌드를 수행합니다. Windows·Android 실기기 최종 검증은 별도입니다.
