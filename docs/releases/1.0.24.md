# d-ddeck 1.0.24 — VPN 알림 해제 수정·로그인 화면 정리

작성일: 2026-10-01

## VPN

- Android 알림의 ‘VPN 연결 해제’가 알림만 없애던 문제를 수정합니다. 연결을 생성한 WireGuard 백엔드와 터널을 공유해 실제 터널을 종료합니다.
- Flutter 화면을 닫거나 다시 열어도 동일한 터널을 해제합니다. 로그인 정보와 등록한 VPN 설정은 유지합니다.
- 터널 종료를 확인한 뒤 알림을 제거합니다. 실패하면 알림에 재시도 안내를 표시합니다.
- 원래 터널 사용, 화면 재생성, 종료 실패 후 재시도, 종료되지 않은 터널 감지에 대한 Android 네이티브 회귀 테스트를 릴리즈 CI에 추가합니다.

## 로그인 화면

- 회사 로고 원본을 사용하고 기존 72 크기에서 260 크기로 확대합니다. 화면 너비에 맞춰 원본 비율을 유지합니다.
- 서버 소개, 자동 로그인 설명, 가입 승인 안내와 로그인 화면의 VPN 설명 문구를 제거합니다.
- 서버 연결 확인은 상단 아이콘으로 이동합니다. 입력 항목, 기능 버튼, 연결 상태 및 오류 안내는 유지합니다.

## 배포 및 확인

- 앱 버전 1.0.24+24. 기존 앱·업데이트 서명 키를 유지합니다.
- 서버 API·DB 스키마 변경이 없어 운영 중인 서버 1.0.23과 호환됩니다.
- Flutter 정적 분석·전체 테스트 및 Android 네이티브 회귀 테스트를 검증한 후 배포합니다.
- 실제 Android 기기에서 앱을 스와이프 종료한 뒤 알림의 VPN 연결 해제를 눌러 VPN 표시가 사라지는지 확인해야 합니다.
