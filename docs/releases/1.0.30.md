# d-ddeck 1.0.30 — 업무별 일지·사진 코멘트·홈 화면 개편·매장 시스템 구성

작성일: 2026-10-08

## 시작 화면

- 앱을 처음 켜면 회사 로고만 크게 보이다가 점점 작아지며 로그인 카드의 로고 자리로 들어가고, 배경이 걷히며 로그인 창이 드러납니다. 화면을 누르면 건너뜁니다. 로그아웃 뒤와 OS의 "애니메이션 줄이기" 설정에서는 생략합니다.

## 근무일지

- **금일 업무를 업무 단위로 입력**합니다. 업무마다 오전/오후, 사무/출장, 출장지(출장일 때 필수), 업무 제목, 상세 내용을 적고 **업무 추가** 버튼으로 늘립니다. 요약·상세·오전·오후 글은 서버가 업무 목록으로 만들어 예전 앱·엑셀과 호환됩니다.
- 업무마다 **사진을 넣고 사진별 코멘트**를 달 수 있습니다. 사진은 저장할 때 올라갑니다.
- **PDF 양식 개편**: 상단 정보에서 문서번호·연장근무 칸을 뺐고, 오전·오후 업무를 위아래 표로, 요약은 업무 제목에 번호를 붙여, 상세는 번호·업무·상세 내용 표로, 업무 사진은 두 장씩 코멘트와 함께 출력합니다.

## 게시판

- 글쓰기·수정 화면에서 **사진마다 코멘트**를 달 수 있습니다.
- 게시글을 열면 **사진이 본문 아래에 바로 크게** 보이고 각 사진 아래에 코멘트가 나옵니다. 첨부 목록에는 사진이 아닌 파일만 나옵니다.
- 게시글 수정·삭제 버튼을 제목 줄 오른쪽 위로 옮겼습니다.

## 홈 화면

- 맨 위에 인사말, 그 아래 **공지사항** 최근 글을 보여 줍니다.
- 요약 칸을 **나에게 배정된 서비스 기준 4칸**(배정 서비스 · 미처리 · 당월 배정 접수 · 종결률)으로 바꾸고, 앞의 세 칸은 누르면 해당 조건의 서비스 목록이 열립니다.
- 연도별 건수 차트와 기한 우선 서비스 칸을 없애고, 미종결 칸을 오늘 일정·렌탈 미회수와 같은 줄에 두었습니다. 칸 사이 간격을 통일했습니다.

## 매장 · 장비 · 통계

- 매장 장비 설정에서 매장의 **시스템 구성(Android / Windows / PLC)**을 고르고, 매장 상세 장비 탭 맨 위와 장비 → 매장 목록에 크게 표시합니다.
- 매장 상세에 **로봇 동작파일** 탭을 추가했습니다. 확장자 제한 없이 보관하되 실행 파일·스크립트는 받지 않습니다.
- 서비스 통계 요약에 **연도별 대응인원** 차트를 추가했습니다. 같은 사람의 이관 코드와 계정 코드(예: '이재룡 주임'과 '이재룡')는 한 줄로 셉니다.

## 백업 · 파일

- Google 백업 화면에 **진행 단계와 진행률**(백업 파일 만들기 · 업로드 · 확인)을 표시합니다.
- 서버 관리 스크립트를 sudo로 실행한 뒤 Google 연결 설정 파일이 root 소유가 되어 백업이 실패하던 문제를 고쳤습니다.
- 새 앱 버전을 게시하면 **예전 버전 설치 파일을 자동으로 지웁니다**(GitHub 릴리즈에는 남아 있음).
- PC에서 첨부·PDF·엑셀·백업 ZIP을 내려받으면 **다운로드 폴더에 저장**합니다(같은 이름은 번호를 붙임).
- 사진을 올릴 때 줄이는 방식을 바꿔 **경계가 깨지지 않습니다**. 이미 올린 사진은 그대로입니다.

## 관리용 스크립트

- `scripts/assign_legacy_tickets.py`: 이관된 기록의 담당자를 나중에 가입한 계정에 연결합니다(미리 보기 후 `--apply`).
- `scripts/set_store_systems.py`: 서비스 대응일지 엑셀의 '매장정보' 시트로 매장 시스템 구성을 채웁니다(미리 보기 후 `--apply`).
