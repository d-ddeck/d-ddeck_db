# d-ddeck 1.0.9 — 입력칸·버튼 간격 개선

내 정보 수정에서 이름·전화번호·직급 입력칸이 맞붙던 문제를 수정하고, 화면 전반의 입력폼과 버튼 간격을 정리했습니다.

- 입력칸과 저장 버튼 사이에 기본 16px 간격을 적용했습니다.
- 첫 입력칸의 제목이 잘리지 않도록 글자 배율에 맞는 상단 여백을 확보했습니다.
- 부서·게시판 설정, 장비 수정, AS 이력·부품 입력에 공통 폼 간격과 스크롤을 적용했습니다.
- 매장·일정·근무일지·관리 화면의 공통 폼 간격을 통일하고 중복 여백을 정리했습니다.
- 좁은 화면에서 버튼과 필터가 줄바꿈될 때 줄 간격을 확보했습니다.

## 검증

UI 소스 72개를 점검했습니다. 내 정보 폼의 화면 크기·글자 크기·테마·밀도 16개 조합과 부서·게시판·장비 폼 12개 조합을 검증했습니다. 전체 Flutter 테스트 161개 통과, 기존 실서버 의존 테스트 19개 생략, 정적 분석 오류 없음.

[점검 내용과 수정 화면](https://github.com/kmeans12345-cell/d-ddeck_db/blob/v1.0.9/docs/UI_SPACING_REVIEW.md)

## 업데이트

- **1.0.8 사용자:** 앱 실행 시 안내 또는 설정 → 업데이트 확인에서 다운로드·설치합니다. 사내 서버에 이번 릴리스 파일이 게시되어 있어야 합니다.
- **1.0.7 이하 사용자:** 이번 설치 파일로 최초 한 번 직접 업데이트해야 합니다.
- Android는 1.0.6 이후와 같은 운영 서명 키를 사용합니다. OS 설치 화면에서 승인이 필요합니다.
- 이번 변경은 클라이언트 UI 수정입니다. 1.0.8 서버를 계속 사용할 수 있으며 DB 마이그레이션은 없습니다.

[클라이언트 업데이트 운영 안내](https://github.com/kmeans12345-cell/d-ddeck_db/blob/v1.0.9/docs/CLIENT_UPDATES.md)

설치 파일은 `SHA256SUMS`, 앱 내 업데이트 정보는 서명된 `update-manifest.json`으로 검증합니다. Windows·Android 실기기에서 OS 설치 과정의 최종 검수는 별도입니다.
