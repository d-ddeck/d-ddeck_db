# d-ddeck 1.0.18

- 전체 주요 화면의 여백과 탭·검색 배치를 정리해 목록 표시 공간을 확대했습니다.
- UI의 대응 명칭을 서비스로 변경하고 전체·종결·미종결 필터를 제공합니다. 접수 버튼과 게시판 글쓰기 버튼은 우측 하단의 펜 + 버튼으로 이동했습니다.
- 서비스 인원 선택 목록은 사용 중인 가입 계정에서 최고관리자를 제외하고 표시합니다. 과거 기록의 인원 정보는 보존합니다.
- 게시판 생성·수정 시 아이콘을 선택할 수 있으며 검색창은 초기화 버튼 왼쪽에 배치합니다.
- 달력은 일요일부터 시작합니다. 편집 가능한 일정을 선택하고 양끝을 드래그하여 시작일·종료일을 조절할 수 있습니다. 참석자 검색, 기간 일정 생성, 일정등록·내 일정 버튼을 제거하고 월 전체 목록 선택은 일정 목록으로 이동했습니다. 날짜 더블클릭·더블탭 일정 생성은 유지됩니다.
- 서비스 상세 화면의 다시 열기·작업 기록 추가 등 처리 버튼을 하단으로 이동했습니다.
- 관리 설정에 Google Drive 자동 백업을 추가했습니다. 계정 연결·변경·해제, 매일 실행 시간 설정, 즉시 백업, 마지막 성공/오류 확인을 지원합니다. 실제 백업 작업은 서버에서 실행됩니다.

## 적용 및 테스트

서버와 앱을 함께 업데이트하세요. DB 마이그레이션 `b951e752d084`는 게시판 아이콘 열을 추가합니다. 기존 DB·첨부파일·서버 환경설정은 릴리즈에 포함하지 않습니다.

Google Drive 백업은 최초에 꺼져 있습니다. 관리자 화면에서 OAuth 앱 설정과 Google 계정 연결을 완료한 후 지금 백업으로 확인하고 자동 백업을 켜세요. 서버 PC에서 연결할 경우 콜백 주소는 `http://localhost:8000/api/v1/admin/drive-backup/callback`입니다. [설정 및 복구 안내](https://github.com/kmeans12345-cell/d-ddeck_db/blob/v1.0.18/docs/google-drive-backup.md)를 참고하세요.

자동 테스트는 인증 취소·재사용 방지·계정 변경·관리자 권한·예약 중복 방지·업로드 결과 확인과 백업 복구 검사를 포함합니다. 실제 Google 계정으로의 업로드는 OAuth 연결 후 별도로 확인해야 합니다.
