# d-ddeck 1.0.15 — 업무 구분에 따른 접수번호 발급·재발급

## 변경 사항

- 신규 접수번호를 선택한 업무 구분 코드로 발급합니다. AS·CS·PO 및 관리자가 추가한 코드별로 월별 순번을 사용합니다.
- 기존 접수도 업무 구분을 변경해 저장하면 변경 시점의 월을 기준으로 새 접수번호를 발급합니다. 같은 업무 구분을 유지하거나 다른 항목만 수정하면 번호를 유지합니다.
- 업무 구분을 선택하지 않거나 해제하면 기본 접두어 설정(기본 AS)을 사용합니다.
- 이전에 발급한 번호는 재사용하지 않습니다. 변경 전·후 번호를 작업 기록과 감사 이력에 남기며, 과거 데이터에서 가져온 접수도 화면과 Excel에 새 번호를 표시합니다.
- 기존 접수의 내부 식별자와 연결된 자료는 유지합니다. 일괄 재발급은 하지 않으며, 업무 구분을 변경해 저장할 때 적용합니다.

## 적용 방법

1. DB와 첨부파일을 백업하고 서버를 중지합니다.
2. 서버를 1.0.15로 업데이트하고 해당 서버 환경에서 `alembic upgrade head`를 적용합니다. 서버 업데이트 도구를 사용하는 경우 도구의 마이그레이션 절차를 따르세요.
3. 서버를 시작하고 정상 동작을 확인한 뒤 앱을 1.0.15로 업데이트합니다.

이번 릴리즈에는 접수번호 열 확장(`e628b429ad51`)과 발급 번호 보존 테이블 추가(`f739c530be62`)가 포함됩니다. 최종 DB 리비전은 `f739c530be62`입니다. 마이그레이션은 기존 접수번호를 보존합니다.

Windows 설치 파일, 서명된 Android APK, Ubuntu 서버 설치 파일, 사용자 가이드 및 서버 운영 매뉴얼을 제공합니다. 다운로드 파일은 SHA256SUMS와 서명된 update-manifest.json으로 검증합니다. 첨부된 일반 매뉴얼과 함께 이 릴리즈의 DB 적용 절차를 확인하세요.

## 검증

로컬에서 서버 기본 테스트 254건, 업무 구분별 발급·재발급·변경 이력·Excel·번호 중복 재시도·저장 실패 복구 검증, DB 마이그레이션 검증, 앱 관련 테스트 16건 및 변경 파일 정적 분석을 통과했습니다. 릴리즈 CI에서 PostgreSQL 및 전체 회귀 검사와 플랫폼별 설치 파일 빌드를 수행합니다.
