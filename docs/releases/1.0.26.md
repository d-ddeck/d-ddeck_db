# d-ddeck 1.0.26 — 영문 로그인 입력·연락처 자동 형식·화면 개선

작성일: 2026-10-06

## 로그인·계정

- 로그인, 회원가입, 비밀번호 변경의 아이디·비밀번호 칸은 영문으로 고정됩니다. 한/영 키가 한글에 놓여 있어도 같은 자판 위치의 영문이 들어갑니다(예: `ㅁ` → `a`).
- Windows는 입력란을 누르면 입력기가 영문 모드로 바뀌고, 모바일은 영문 자판으로 열립니다.
- 이전에 한글이 섞인 비밀번호를 쓰던 계정은 로그인되지 않을 수 있습니다. 관리자가 비밀번호를 초기화해 주세요.

## 연락처 자동 형식

- 서비스 접수, 매장, 회원가입, 내 정보, 견적서의 연락처에 숫자를 입력하면 자동으로 하이픈이 들어갑니다.
  - 휴대폰·070 `010-1234-5678`, 지역번호 `031-123-4567`, 서울 `02-1234-5678`, 대표번호 `1588-1234`
- `+82`나 `내선` 같은 글자가 든 기존 값은 그대로 둡니다. 저장된 번호를 일괄 변환하지는 않습니다.

## 서비스 접수·캘린더·알림

- 서비스 접수에서 브랜드보다 매장을 먼저 고르면 그 매장의 브랜드가 자동으로 선택되고, 매장 목록도 그 브랜드로 좁혀집니다.
- 캘린더에서 일정을 선택한 뒤 다른 곳을 누르면 선택이 해제됩니다.
- 등록·삭제 후 하단 알림(상세 보기)이 3초 뒤 아래로 내려가며 사라집니다. 오류 알림은 4초입니다.

## 관리

- 관리 > 설정 > **매장**에서 매장 브랜드 종류를 추가·수정·사용 중지할 수 있습니다.

## 배포 및 확인

- 앱 버전 1.0.26+26. 기존 앱·업데이트 서명 키를 유지합니다.
- 서버 API·DB 스키마 변경이 없어 서버 1.0.25와 호환됩니다. 서버는 버전 표기만 바뀝니다.
- Windows 입력기 영문 전환과 Android 영문 자판은 실제 기기에서 확인이 필요합니다.
