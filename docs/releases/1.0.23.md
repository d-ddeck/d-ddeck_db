# d-ddeck 1.0.23 — 캘린더 위젯·알람·VPN 알림 개선

작성일: 2026-10-01

## 앱 화면

- 로그인 화면에 회사 로고를 표시합니다.
- Android 하단 메뉴에 캘린더를 배치하고 근무일지는 더보기로 이동합니다.
- Android 홈에서 뒤로가기를 누르면 로그아웃 확인창을 표시합니다.
- 홈에 전체 기간 총 접수·미종결 건수를 추가합니다.
- 서비스 대응인원 수정 시 현재 가입자와 기존 기록에 사용된 인원(비활성 포함)을 선택할 수 있습니다. 신규 접수는 기존 가입자 목록 정책을 유지합니다.

## 일정·알람·위젯

- 알람 날짜와 시각을 직접 지정합니다. 일정 시작 전후 14일 이내이며 종일 일정의 시작 이후 시각도 지정할 수 있습니다.
- 기본 알람·맑은 벨·부드러운 알림 중 알람음을 선택합니다.
- Android 위젯에 이번 달 달력과 선택 날짜의 일정을 표시합니다. 알람 없는 일정도 포함합니다.
- 위젯 새로고침은 앱의 서버 동기화 화면을 열며, 연결 실패 시 VPN 설정·로그인·재시도를 안내합니다.
- 앱이 닫혀 있을 때 위젯은 마지막 저장 내용을 표시합니다. 서버 동기화는 앱에서 실행되며 저장 시각을 표시합니다.
- 캘린더 캐시는 로그아웃·계정 전환 시 정리하고 늦게 도착한 이전 계정 응답을 저장하지 않습니다.

## VPN

- Android ‘디떽 사외 접속’ 알림에 VPN 연결 해제 버튼을 추가합니다. Flutter 화면이 닫혀 있어도 네이티브 서비스에서 터널을 종료합니다.
- VPN 해제 시 알림과 연결 상태를 갱신하며 앱 로그인 정보와 등록한 VPN 설정을 유지합니다.
- Windows의 서비스 실행 상태는 ‘터널 실행 중’으로 표시합니다. 이 표시는 서버 접속 성공 여부와 구별됩니다.
- Android 알림 변경을 유지하기 위해 wireguard_flutter_plus 1.0.7을 라이선스와 함께 저장소에 포함했습니다. Dart·Windows·Darwin 구현은 원본을 유지합니다.

## 서버 및 저장소

- SQLite DB 외장디스크/DAS 이전 도구와 디스크 UUID 시작 검사를 추가합니다.
- 이전 도구는 기본적으로 계획만 검사하며 명시적 적용 시 Google 안전 백업·DB 무결성·새 DB 사용 여부를 확인합니다.
- 현재 서버 DB는 기존 경로를 유지합니다. 외장디스크 연결 후 별도 이전해야 합니다. 첨부파일 이전은 이 도구의 범위에 포함되지 않습니다.
- 백업 후 종료·예약 기동은 이번 버전에서 활성화하지 않습니다.
- DB 스키마 변경은 없지만 기존 대응인원 선택과 일정 시작 이후 알람 저장에는 서버 1.0.23 반영이 필요합니다.
