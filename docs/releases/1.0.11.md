# d-ddeck 1.0.11 — 모바일 캘린더 여백·스크롤 개선

휴대폰 캘린더 화면의 하단이 잘리던 배치를 수정하고, 필터·달력·일정 목록 전체를 위아래로 스크롤할 수 있도록 개선했습니다.

- 하단 시스템 영역을 피하는 안전 여백과 목록 끝 여백을 확보했습니다.
- 화면 높이에 맞춰 달력을 고정하던 모바일 배치를 하나의 세로 스크롤로 변경했습니다.
- 휴대폰 가로 화면에서도 손가락으로 달력을 스크롤할 수 있습니다. PC의 마우스 날짜 범위 선택은 유지합니다.
- 큰 글씨 설정에서 날짜 숫자가 잘리지 않도록 날짜 영역 높이와 배치를 조정했습니다.
- Android 홈 화면 일정 알람 위젯을 포함한 기존 기능은 유지합니다.

## 검증

작은 휴대폰·일반 휴대폰·가로 화면에서 글자 크기 100%/200%, 6주 달력, 하단 안전 여백과 상하 스크롤을 검증했습니다. 손가락 스크롤과 마우스 범위 선택도 확인했습니다. Flutter 전체 테스트 173개 통과, 기존 실서버 의존 테스트 19개 생략, 정적 분석 오류 없음. 실제 휴대폰 화면과 OS 설치 과정의 최종 검수는 별도입니다.

## 업데이트

- **1.0.8 이상:** 앱 재실행 또는 설정 → 업데이트 확인에서 다운로드·설치합니다. 사내 서버에 이번 릴리스가 게시되어 있어야 합니다.
- **1.0.7 이하:** 이번 설치 파일로 한 번 직접 업데이트하세요.
- 기존 1.0.8 이상 서버를 계속 사용할 수 있습니다. 서버 재시작이나 DB 마이그레이션은 필요 없습니다.
- Android는 기존 운영 서명 키를 유지합니다. OS 설치 화면에서 승인이 필요합니다.

배포 파일은 `SHA256SUMS`, 앱 업데이트 정보는 서명된 `update-manifest.json`으로 검증합니다.
