# d-ddeck 1.0.21 — 서비스 접수·장비 및 매장 UI·Windows VPN 개선

작성일: 2026-10-01

## 서비스 접수

- 발생일시는 현재 시각으로 기본 입력하며 날짜와 시간을 수정할 수 있습니다.
- 신규 접수에서 접수·진행중·종결 상태를 선택해 저장할 수 있습니다. 종결 시 처리 내용과 서비스 인원 검증을 유지하고 진행·종결 시각 및 이력을 함께 기록합니다.
- 신규 접수의 기타 항목을 비고 입력란으로 변경하고 접수 이력에 저장합니다. 기존 기록의 부가 정보 수정은 유지합니다.
- 접수 화면에서 여러 첨부파일을 선택하고 저장 직후 업로드할 수 있습니다. 업로드 실패 시 접수를 중복 생성하지 않고 남은 파일을 재시도합니다.

## 장비·매장 및 설정 화면

- 매장 등록 버튼을 우측 하단의 매장 아이콘과 + 버튼으로 이동했습니다.
- 장비 등록을 3점 메뉴에서 제거하고 장비 목록 우측 하단의 장비 아이콘과 + 버튼으로 이동했습니다.
- 등록 버튼에 마지막 목록이 가려지지 않도록 하단 스크롤 여백을 추가했습니다.
- 미운영 매장을 브랜드별 운영 집계와 구분해 별도 카드·목록으로 표시합니다. 기존 폐점 포함 버튼은 제거했습니다.
- 폐점 문구를 미운영으로 통일하고 미운영 화면의 중복 필터 문구를 제거했습니다. 기존 상태값과 집계 방식은 유지합니다.
- 이 기기 연결 설정과 시스템 설정 사이 간격을 통일했습니다.

## 연결 및 Windows VPN

- 기본 HTTPS 서버 주소와 WireGuard 분할 터널 기본 대역을 이전한 운영 환경에 맞게 갱신했습니다.
- VPN 관리자 승인 이전의 불필요한 설정 폴더 소유자 변경을 제거하고 접근 권한만 제한하도록 수정했습니다.
- 관리자 권한으로 실행한 WireGuard 프로세스의 종료 결과 처리를 보완했습니다.
- 설정 폴더 접근·파일 저장·서비스 등록·시작·제거 오류를 구분합니다. 오류 메시지에 설정 원문이나 개인키를 표시하지 않습니다.
- 운영 서버의 HTTPS 적용 및 IP 변경 절차를 문서에 반영했습니다.

## 배포 및 확인 사항

- 앱 버전: 1.0.21+21 / 서버 버전: 1.0.21.
- 신규 접수의 상태 저장 기능은 서버와 앱을 함께 업데이트해야 합니다.
- 기존 HTTP 연결 설정을 쓰는 기기는 HTTPS 관리자 연결 설정을 가져와야 합니다. 등록된 연결 설정은 일반 앱 업데이트 후에도 유지됩니다.
- Windows VPN은 기존 버전에서 관리자 실행 시 연결되는 것을 확인했습니다. 이번 수정본의 일반 권한 실행·UAC 승인·실제 연결은 배포 후 해당 Windows PC에서 재검증해야 합니다.
- DB 스키마 변경은 없습니다.

## 로컬 검증

- Flutter 전체 테스트 281개 통과, 환경별 테스트 19개 건너뜀.
- Dart 전체 분석 및 Python Ruff 검사 통과.
- 임시 DB에서 접수 상태 전환·비고·실패 롤백, 매장 연락처, 서명된 클라이언트 업데이트 검증 통과.
- Windows 릴리즈 빌드에 앱 내부 PowerShell 구문 검사를 추가했습니다. 실제 Windows 일반 권한 연결 검증은 별도로 필요합니다.
