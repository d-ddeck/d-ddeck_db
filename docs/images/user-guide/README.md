# 사용자 가이드 화면 캡처

- 촬영일: 2026-09-26
- 앱: d-ddeck 1.0.5+5, Flutter Linux 개발용 데스크톱 빌드
- 방식: 실제 앱과 별도 FastAPI 서버를 실행한 뒤 Flutter `integration_test`로 로그인·메뉴 이동. 앱 최상위 `RepaintBoundary`를 PNG로 저장했습니다. 디자인 목업이나 합성 화면이 아닙니다.
- 크기: 논리 화면 1440×1000, 저장 이미지 2160×1500 (1.5배)
- 데이터: 별도 임시 SQLite DB에 데모 사용자·AS 60건·장비 24건·가상 매장 3곳·근무일지·일정·알림을 생성했습니다. 운영 데이터·운영 계정은 사용하지 않았습니다.
- 계정: 안내용 관리자 계정. 로그인 화면은 비밀번호 입력 전 캡처했습니다. 토큰 저장소는 테스트 메모리 저장소를 사용했습니다.
- 화면 범위: 앱 콘텐츠만 저장했습니다. 다른 프로그램이나 운영체제 바탕화면은 포함하지 않습니다.
- 한계: Android 실기기 화면, 푸시 수신, 기기 알람 울림, 운영 백업 성공을 촬영한 자료는 아닙니다. 서버 상태 화면은 스케줄러를 끈 시험 환경의 실제 결과입니다.

이미지별 사용 순서와 설명은 [사용자 가이드](../../사용자-가이드.md)를 참고하세요. 각 파일명의 번호는 캡처 식별 번호이며, 문서의 읽는 순서와 같지 않을 수 있습니다.

## 문서 재생성

Markdown과 PNG를 수정한 뒤 저장소 루트에서 실행합니다. 앱 실행용 의존성과 별도로 Python `Markdown==3.8.2`가 필요합니다.

```bash
python3 docs/tools/build_user_guide.py
python3 docs/tools/build_user_guide.py --pdf --chrome /usr/bin/google-chrome
```

HTML에는 PNG가 내장됩니다. PDF 생성에는 로컬 Chrome/Chromium과 한글 글꼴이 필요합니다. 외부 웹사이트나 외부 변환 서비스에 이미지를 업로드하지 않습니다.
