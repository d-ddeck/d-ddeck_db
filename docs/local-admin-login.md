# 서버 PC 관리자 자동 로그인

서버 PC에서 최초 실행부터 관리자 계정으로 들어가는 선택 기능입니다. 배포 파일에는 인증정보가 없으며, 서버 PC의 데스크톱 OS 계정에만 별도로 설정합니다. 일반 PC·Android는 기존 로그인 방식을 사용합니다.

서버의 `backend` 디렉터리에서 데스크톱을 사용하는 OS 계정으로 실행합니다.

```bash
# Linux
DEBUG=false .venv/bin/python scripts/configure_local_admin.py --account admin
```

```powershell
# Windows
$env:DEBUG = "false"
.venv\Scripts\python.exe scripts\configure_local_admin.py --account admin
```

앱을 다시 실행하면 저장된 로그인 이력 없이 로컬 서버 `http://127.0.0.1:8000`에 관리자 자동 로그인을 시도합니다. 서버 포트가 다르면 설정 명령에 `--server-url http://127.0.0.1:포트`를 지정하세요. 서버가 먼저 실행 중이어야 합니다. 동명이인 계정 식별을 피하려면 `--account`에 전체 이메일을 지정할 수 있습니다.

인증정보는 사용자 프로필의 `.ddeck/local-admin-login.json`, 서버의 검증 정보는 `backups/.local-admin/credential.json`에 저장합니다. 인증 파일은 사용자 전용 권한으로 생성하며 다른 PC나 계정으로 복사하지 마세요. 서로 다른 OS 계정으로 서버와 앱을 실행한다면 서버가 검증 파일을 읽을 수 있는 권한도 필요합니다. 파일 내용은 로그·설정 API·릴리즈·클라우드 백업에 포함하지 않습니다.

서버는 루프백 주소와 전용 인증정보를 함께 확인합니다. 브라우저 Origin이나 프록시 전달 헤더가 있는 요청은 거부합니다. 계정 정지·삭제·관리자 권한 해제·비밀번호 변경은 자동 로그인을 무효화합니다. 비밀번호 변경 뒤 다시 사용하려면 설정 명령을 재실행하세요. 필수 비밀번호 변경 정책은 그대로 적용됩니다.

해제하려면 같은 명령에 `--disable`을 추가하고 앱에서 로그아웃합니다. 이미 발급한 세션은 계정 설정의 세션 목록에서 해제할 수 있습니다. 앱에서 로그아웃하면 해당 실행 중에는 로그인 화면을 유지하며, 다음 실행 시 전용 인증정보가 있으면 다시 자동 로그인합니다.
