# 입력 제목 잘림 점검 — 2026-09-27

## 원인 및 수정

Windows 캘린더의 ‘참석자 검색’에서 테두리 위에 떠 있는 제목이 스크롤 영역 상단 밖으로 그려졌습니다. 기존 코드로 재현한 위젯 테스트에서 스크롤 시작 좌표 80px보다 제목이 위인 74.5px에 배치됐습니다. 단순히 입력창 높이를 키우는 대신 스크롤 안쪽에 글자 배율에 비례하는 상단 여백을 확보했습니다.

| 점검 대상 | 결과·조치 |
| --- | --- |
| 캘린더 참석자 검색 | 달력 필터 묶음 안쪽에 제목 여백 추가. 좌우 분할/단일 스크롤 모두 적용 |
| 공통 FilterBar | 데스크톱 필터 첫 줄에도 제목 여백 추가. 계정 검색·근무일지·AS 통계 등 공통 사용 화면에 적용 |
| AS 상세 검색 조건 | 내부 스크롤 첫 드롭다운 제목 여백 추가 |
| AS 상태 변경·작업 기록 추가 | 중첩된 내부 스크롤의 첫 입력칸 제목 여백 추가 |
| 프로필·장비·일정·매장·게시판·근무일지 입력 | FormFields/FormListView/FormSection 또는 명시적 내부 여백 확인. 기존 보호 유지 |
| 계정·감사 로그 관리 | 기존 탭/스크롤 경계 테스트 유지·통과 |
| 로그인·회원가입·비밀번호 변경·공통 확인 대화상자 | 카드·대화상자 내부 여백 확인. 단, 별도 내부 스크롤은 그 경계에서 따로 보호해야 함 |
| 힌트만 있는 검색창 | 떠 있는 제목이 없어 이번 상단 잘림 유형에는 해당하지 않음 |

공통 `fieldLabelInsets(context)`로 글자 배율에 따른 제목 여백을 계산합니다. 입력칸 테마의 항상 보이는 제목을 유지하며 클리핑을 해제하지 않습니다.

## 점검 범위와 검증

- UI Dart 소스 **73개**, `labelText` 선언 **93곳**의 부모 배치·스크롤·고정 높이·공통 입력 컴포넌트 사용을 점검했습니다. 선언 수는 반복 생성되는 실제 입력칸 수와 다릅니다.
- 캘린더: 창 너비 1000/1440, 글자 배율 100/150/200%, 라이트/다크, 기본/촘촘한 간격 **24개 조합**. 빈 값과 입력·포커스 상태에서 스크롤 상단 안에 제목이 남는지 검증합니다.
- 공통 검색 필터 및 대화상자 내부 입력 패턴 **24개 조합**. 텍스트 입력과 드롭다운 제목을 함께 검증합니다.
- 새 데스크톱 테스트는 Windows 테마 설정으로 실행합니다. 실행 호스트는 Linux이며 **Windows 실기기에서 모든 업무 화면을 직접 실행한 검수는 아닙니다**. 업무 데이터가 필요한 화면은 소스와 공통 배치 패턴을 점검했습니다.
- 전체 Flutter 테스트 **221개 통과**, 기존 실서버 의존 19개 생략. 정적 분석 오류 없음.

1.0.12에 포함됩니다. 릴리스 후 Windows에서 디스플레이 배율 및 실제 글꼴에 따른 최종 표시를 확인해야 합니다.
