# Android 홈 화면 일정 알람 위젯

## 추가 방법

1. 캘린더 위젯 개선이 포함된 Android 앱을 설치하고 실행합니다. 현재 작업본은 아직 배포 전입니다.
2. 사내망 또는 VPN에 연결하고 로그인합니다. 위젯의 **새로고침**으로 캘린더를 동기화합니다.
3. Android 홈 화면의 빈 공간을 길게 누르고 **위젯 → d-ddeck 일정 알람**을 선택하여 배치합니다. 런처에 따라 메뉴 이름은 다를 수 있습니다.
4. 위젯을 길게 눌러 가로·세로 크기를 조절합니다. 목록은 세로로 스크롤할 수 있습니다.

## 표시와 조작 (현재 작업본, 미배포)

- 이번 달 달력을 일·월·화·수·목·금·토 순서로 표시합니다. 일정이 있는 날짜에는 점을 표시합니다.
- 날짜를 누르면 해당 날짜와 겹치는 일정 목록을 표시합니다. 종일 일정과 알람을 설정하지 않은 일정도 포함합니다.
- 제목 또는 새로고침을 누르면 앱의 위젯 캘린더 동기화 화면을 엽니다. 사용자 터치로 Activity를 직접 실행하므로 백그라운드에서 뒤늦게 앱을 여는 방식에 의존하지 않습니다.
- 연결 실패 시 마지막 저장 내용은 유지하며 앱에서 VPN 설정·로그인 화면으로 이동하거나 다시 동기화할 수 있습니다.
- 일정 항목을 누르면 동기화 후 서버의 일정 상세를 조회합니다. 삭제 또는 권한 변경으로 조회할 수 없으면 안내합니다.
- 위젯은 마지막 저장 시각을 표시합니다. 연결되지 않았을 때 저장된 목록을 최신 정보로 취급하지 마세요.
- 위젯의 날짜 선택은 같은 앱의 모든 위젯에서 공유합니다. 현재 월 밖의 일정 탐색은 앱 캘린더에서 합니다.

## 갱신과 데이터 수명

앱의 Android 일정 동기화 주기에 캘린더도 조회합니다. 앱이 실행되지 않을 때 OS의 주기 갱신은 저장본만 다시 표시하며 서버 통신을 하지 않습니다. 서버 조회는 앱의 기존 로그인·인증서·VPN 연결을 사용합니다.

캘린더 캐시는 알람 예약과 별도입니다. 로그아웃·계정 전환 시 캘린더 캐시는 비우며, 다른 계정의 늦은 응답이 저장되지 않도록 검사합니다. 기존에 휴대폰에 예약한 알람은 기존 정책대로 유지합니다. 알람 전체 삭제 기능은 이 캘린더 캐시와 별개입니다.

## 구현 및 검증

- `WidgetCalendarStore`: `FlutterSharedPreferences`의 `flutter.calendar_widget.synced`에 접근 가능한 이번 달 일정만 저장합니다. 위젯에 인증 토큰을 복사하지 않습니다.
- Android 12 이상은 RemoteCollectionItems, 이전 버전은 BIND_REMOTEVIEWS로 보호한 RemoteViewsService를 사용합니다.
- 새로고침과 일정 항목은 MainActivity를 직접 열고 Flutter 동기화 화면으로 전달합니다.
- 현재 작업본: Flutter 전체 테스트 287개 통과, 실서버 의존 19개 생략, 정적 분석 통과. 42개 달력 셀의 XML ID도 검사했습니다.
- 현재 개발 PC에 Android SDK가 없어 APK 빌드는 수행하지 못했습니다. Kotlin 컴파일과 실기기 위젯 추가·크기 조절·날짜 선택·VPN 연결 실패·재시작 검증은 Android 빌드 환경에서 진행해야 합니다.

기존 1.0.10 위젯은 저장된 알람만 표시했으며 새로고침도 로컬 목록만 다시 읽었습니다. 위 설명은 이후 개선 작업본 기준입니다.
