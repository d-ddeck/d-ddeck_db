# Android 홈 화면 일정 알람 위젯

## 추가 방법

1. 1.0.10 이상 Android 앱을 설치하고 실행합니다.
2. 사내망 또는 VPN에 연결하고 로그인합니다. **이 폰의 알람 → 다시 동기화**로 저장 목록을 확인합니다.
3. Android 홈 화면의 빈 공간을 길게 누르고 **위젯 → d-ddeck 일정 알람**을 선택하여 배치합니다. 런처에 따라 메뉴 이름은 다를 수 있습니다.
4. 위젯을 길게 눌러 가로·세로 크기를 조절합니다. 목록은 세로로 스크롤할 수 있습니다.

## 표시와 조작

- 서버 알림함의 AS·게시판 알림이 아니라 **이 폰의 알람에 저장된 일정 알람**을 표시합니다. 이 데이터에는 읽음 상태가 없으므로 미래의 알람을 시간순으로 최대 50개 표시합니다.
- 알람 시각, 제목, 캘린더, 장소를 보여줍니다. 위젯 색상은 휴대폰의 시스템 라이트·다크 모드를 따릅니다.
- 항목을 누르면 앱에서 저장된 상세를 엽니다. 서버에 연결되지 않아도 볼 수 있습니다.
- 저장한 계정으로 로그인한 경우 **서버의 일정 상세 보기**로 최신 일정을 조회할 수 있습니다. 삭제되었거나 권한이 없으면 앱에서 오류를 안내합니다.
- 위젯 제목을 누르면 앱의 **이 폰의 알람** 목록으로 이동합니다.
- **새로고침**은 휴대폰에 저장된 목록을 다시 읽습니다. 서버 요청이나 앱 실행 없이 동작합니다. 최신 서버 변경 사항은 앱에서 **다시 동기화**해야 합니다.
- 마지막 저장 시각은 서버 알람 목록을 앱에 저장한 시각입니다. 새로고침을 누른 시각이 아닙니다.

## 갱신과 데이터 수명

앱에서 알람 동기화·전체 삭제가 완료되면 모든 위젯에 반영합니다. 앱 실행, 위젯 크기 변경, 시간대 변경 및 OS의 주기 갱신에서도 저장 목록을 다시 읽습니다. OS 주기 갱신은 30분 간격을 요청하며 절전 상태에서는 지연될 수 있습니다. 따라서 알람 시간이 지났다고 목록에서 즉시 사라지는 것은 아닙니다. 새로고침을 누르면 현재 시각 기준으로 다시 필터링합니다.

표시 시각은 서버에서 동기화해 저장한 원래 알람 시각입니다. 울림 화면에서 선택하는 임시 **다시 울림** 예약 시각이나 OS의 예약 성공 여부는 나타내지 않습니다. 위젯은 기존 알람 예약·울림 동작을 변경하지 않습니다.

기존 앱 정책에 따라 로그아웃 후에도 휴대폰에 저장된 알람과 위젯 목록은 유지됩니다. **이 폰의 알람 → ⋮ → 이 폰의 알람 모두 지우기**를 선택하면 위젯도 비워집니다. 다른 계정으로 동기화하면 새 계정 목록으로 교체됩니다. 위젯의 과거 항목을 눌러도 현재 저장본에 없는 알람은 상세를 표시하지 않습니다.

## 구현 및 검증

- `SyncedAlarmStore`가 사용하는 legacy shared_preferences 저장소(`FlutterSharedPreferences`, `flutter.calendar_alarm.synced`)를 네이티브 위젯이 직접 읽습니다. 저장소를 DataStore 등으로 전환할 때 이 연동도 함께 변경해야 합니다.
- Android 12 이상은 RemoteCollectionItems, 이전 버전은 BIND_REMOTEVIEWS로 보호된 RemoteViewsService를 사용합니다. [Android 공식 컬렉션 위젯 문서](https://developer.android.com/develop/ui/views/appwidgets/collections)를 기준으로 구현했습니다.
- 위젯은 인증 토큰을 복사하거나 자체 서버 요청을 수행하지 않습니다.
- Flutter 테스트는 저장·삭제 후 갱신 순서, 네이티브 갱신 오류 시 저장본 보존, 앱 최초/재실행 진입 신호 소비, 삭제된 항목, 오프라인 상세를 확인합니다.
- 실기기에서는 위젯 추가/여러 개 배치, 화면 크기·글자 배율·다크모드, 앱 종료 후 새로고침과 항목 선택, 삭제·재동기화, 재부팅을 확인해야 합니다. 개발 환경에 연결된 Android 기기는 없습니다.

### 개발 검증 결과

Flutter 전체 테스트 166개 통과, 실서버 의존 19개 생략, 정적 분석 오류 없음. ARM64 릴리스 APK 빌드 성공. 디버그 APK 빌드는 기존 WireGuard tunnel 라이브러리의 D8 Record desugaring 오류로 완료되지 않았으며, 위젯 코드의 Kotlin 컴파일은 통과했습니다. 1.0.10에 포함됩니다. 홈 화면 런처에서의 실기기 검증은 별도입니다.
