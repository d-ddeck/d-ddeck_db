# 입력폼 간격 점검

첨부 화면에서 내 정보 수정의 이름·전화번호·직급 입력칸이 간격 없이 이어지는
문제를 재현했습니다. 수정 전 위젯 측정값은 0px이며 수정 후 최소 16px입니다.

## 적용 기준

- 세로 입력칸과 저장 버튼 사이: 기본 16 논리 픽셀.
- 첫 입력칸 위쪽: 8 논리 픽셀을 글자 배율에 맞춰 확보해 떠 있는 제목의 잘림 방지.
- 화면이 좁아 버튼·필터가 다음 줄로 넘어갈 때: 줄 간격 12 논리 픽셀.
- 입력칸과 같은 줄의 저장·삭제 버튼: 12 논리 픽셀.
- 공통 `FormFields`, `FormListView`, `FormSection`에서 간격을 처리하고,
  기존 섹션 안에 중복 삽입된 `FormGap`은 제거했습니다.

## 점검 범위와 수정

`app/lib/ui`의 72개 Dart 파일에서 입력칸, 드롭다운, 폼 섹션, 버튼 줄바꿈 구성을
점검했습니다. 모든 업무 화면을 실서버 데이터로 직접 실행한 검수는 아닙니다.

| 영역 | 수정 내용 |
|---|---|
| 내 정보·회원가입·인증 | 반복 입력칸과 저장 버튼 간격, 공통 폼 여백 |
| 부서·게시판 관리 | 붙어 있는 입력칸·선택칸 분리, 긴 다이얼로그 스크롤 |
| 장비 수정·등록·위치·출고 대조 | 공통 입력폼, 안내문·입력칸·작업 버튼 사이 간격 |
| AS | 처리 이력·사용 부품 다이얼로그, 발생·고객 정보의 섹션 간격, 통계 선택칸 여백 |
| 매장·장비 세트 | 폼 섹션 간격, 세트 이름과 저장 버튼 사이 여백 |
| 캘린더 | 생성 폼 간격·스크롤, 첫 입력칸 제목 여백, 알림 선택칸과 삭제 버튼 간격 |
| 근무일지·계정·알림·목록·상세 | 공통 폼 간격과 버튼·필터가 줄바꿈될 때의 여백 |

## 검증

- 내 정보: 390px·1440px × 기본·200% 글자 × 라이트·다크 × 기본·좁은 간격 설정의 16개 조합.
- 부서·게시판·장비 폼: 모바일 200% 글자/데스크톱, 라이트/다크의 12개 조합.
- 부서명 오류 표시 후 입력칸 간격과 장비 저장 버튼까지의 스크롤 확인.
- 전체 Flutter 테스트 161개 통과, 기존 실서버 의존 테스트 19개 생략. 정적 분석 오류 없음.
