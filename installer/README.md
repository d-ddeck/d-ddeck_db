# Windows 설치 파일 만들기

사용자에게 전달할 `ddeck-setup-1.0.5.exe` 한 개를 만듭니다.
관리자 권한 없이 설치되고, **설치 중 서버 주소를 물어봅니다.**

---

## 만들기

```powershell
.\installer\build.ps1 -ServerUrl "http://miniserver.local:8000"
```

Flutter 릴리스 빌드 → Inno Setup 컴파일을 이어서 하고 `dist\` 에 남깁니다.
`-ServerUrl` 은 설치 마법사에 **미리 채워지는 값**이며, 설치하는 사람이 바꿀 수 있습니다.

| 옵션 | 설명 |
|---|---|
| `-ServerUrl` | 기본 서버 주소 (기본 `http://ddeck.local:8000`) |
| `-Version` | 설치 파일 버전 (기본: `pubspec.yaml` 에서 읽음) |
| `-SkipFlutterBuild` | 기존 빌드 결과로 패키징만 (빠른 재시도용) |

### 필요한 도구

```powershell
winget install --id JRSoftware.InnoSetup
```

Flutter와 Visual Studio 2022는 앱 빌드에 이미 필요한 것들이고,
**Windows 개발자 모드**도 켜져 있어야 합니다(플러그인 심볼릭 링크).

---

## 배포

`dist\ddeck-setup-1.0.5.exe` **파일 하나만** 전달하면 됩니다. (약 10.5MB)

사용자가 실행하면:

1. 언어 선택 (한국어/영어)
2. 설치 폴더
3. 바탕화면 아이콘 여부
4. **서버 주소 입력** ← 미리 채워져 있고, 모르면 관리자에게 문의하도록 안내
5. 설치 → 시작 메뉴·바탕화면 아이콘 생성, 제거 프로그램 등록

관리자 권한이 없으면 `Program Files` 대신 사용자 폴더에 설치됩니다.
어느 쪽이든 정상 동작합니다.

### IT 일괄 배포 (무인 설치)

```powershell
ddeck-setup-1.0.5.exe /VERYSILENT /SERVERURL="http://miniserver.local:8000"
```

| 인자 | 설명 |
|---|---|
| `/VERYSILENT` | 화면 없이 설치 |
| `/SERVERURL="..."` | 서버 주소 지정 (스킴 없이 적어도 `http://` 자동 보정) |
| `/DIR="..."` | 설치 경로 지정 |
| `/SUPPRESSMSGBOXES` | 대화상자 억제 |
| `/LOG="경로"` | 설치 로그 |

제거: 설정 > 앱에서 "d-ddeck" 또는 설치 폴더의 `unins000.exe`

## 서버 주소가 정해지는 순서

앱은 아래 순서로 접속 주소를 결정합니다.

```
1. 사용자가 앱에서 직접 설정한 주소      ← 가장 우선
2. ddeck.config.json  (설치 프로그램이 기록)
3. --dart-define=SERVER_URL  (빌드 시점)
4. 플랫폼 기본값 (127.0.0.1 / 10.0.2.2)
```

**서버를 옮겼을 때**는 두 가지 방법이 있습니다.

- 설치 폴더의 `ddeck.config.json` 을 고치고 앱 재시작
  ```json
  { "server_url": "http://192.168.0.51:8000" }
  ```
- 새 주소로 설치 파일을 다시 만들어 재설치

어느 쪽이든, **설정 파일의 주소가 이전과 달라지면 앱이 자동으로 새 주소를 채택**합니다.
사용자가 예전에 앱에서 직접 주소를 입력했더라도 마찬가지입니다.
이 동작이 없으면 서버를 옮겼을 때 일부 PC만 옛 주소에 남아 연결이 끊깁니다.

> `.local` 이름(`http://miniserver.local:8000`)을 쓰면 미니PC의 IP가 바뀌어도
> 재배포가 필요 없습니다. 다만 mDNS를 지원하지 않는 기기가 있을 수 있으니,
> 공유기에서 미니PC에 고정 IP(DHCP 예약)를 걸어두는 편이 안전합니다.

## 알아둘 것

**첫 실행 시 SmartScreen 경고가 뜹니다.** 코드 서명 인증서가 없기 때문입니다.
"추가 정보" → "실행"을 누르면 됩니다. 사용자에게 미리 안내하세요.
없애려면 코드 서명 인증서(연 10만원대~)가 필요합니다.

**백엔드가 먼저 떠 있어야 합니다.** 앱만 설치하고 서버가 없으면
로그인 화면에서 연결 오류가 납니다. 서버 설치는
[../deploy/README.md](../deploy/README.md) 참고.

**안드로이드는 설치 파일이 따로 필요 없습니다.** APK 자체가 설치 파일입니다.

```powershell
cd app
flutter build apk --release --target-platform android-arm64 `
  --dart-define=SERVER_URL=http://miniserver.local:8000
```

안드로이드에는 `ddeck.config.json` 방식이 적용되지 않으므로
(앱 폴더에 접근할 수 없습니다) **빌드 시점에 주소를 넣거나**,
사용자가 로그인 화면에서 직접 입력해야 합니다.

## 검증한 것

- 무인 설치 → 설정 파일 기록 → 앱 실행 → 제거까지 실제로 확인
- 주소 정규화: `192.168.0.77:8000` → `http://192.168.0.77:8000`
- 설정 파일 읽기 단위 테스트 5건 (정상/정규화/파일없음/깨진JSON/빈값)
- 전체 테스트 38건 통과 (단위 18 + 실서버 계약 19 + 실제 앱 구동 1)
