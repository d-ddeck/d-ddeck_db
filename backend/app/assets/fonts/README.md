# Embedded quotation font

Nanum Gothic Regular from Google Fonts (NAVER), licensed under the SIL Open Font License 1.1.

- Font source: https://github.com/google/fonts/blob/main/ofl/nanumgothic/NanumGothic-Regular.ttf
- License: [OFL.txt](OFL.txt)

The font is embedded/subset in quotation PDFs so Korean text is portable across Linux, Windows and Android PDF viewers. The source company spreadsheet is not redistributed here.
